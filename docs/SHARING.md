# Share BurnZombies

**Keep yesterday’s agent runs from slowing down today’s.**

BurnZombies connects to the agent harness you already use. Your agent identifies abandoned workers; the native Mac app handles guarded stops and shows the resources recovered. You build. We burn.

- [Social card](media/social-card.jpg) — 1280 × 640, ready for a link preview or announcement.
- [Cleanup clip](media/live-cleanup.mp4) · [GIF](media/live-cleanup.gif) — actual app captures before and after a verified helper cleanup. The verification wait is shortened in the clip.
- [App screenshot](media/live-impact.jpg) · [Mascot](../Sources/BurnApp/Resources/EmberSkull.png).
- [Install](INSTALL.md) · [MCP tools](MCP.md) · [Roadmap](ROADMAP.md).

macOS 14+, Apple Silicon and Intel. MIT licensed. No BurnZombies account, cloud service or subscription. One installer connects Codex, Claude Code, Cursor, GitHub Copilot CLI and Gemini CLI. Cleanup uses the agent’s ownership evidence and existing permissions; no launch wrapper or computer reboot. The clip shows one local run, not a universal performance claim.

Link to **https://github.com/swordfish444/BurnZombies** so people can install, inspect the code, and report what their agents leave behind.

## Rebuild the assets

Serve the repository locally and capture `docs/media/social-card.html` at 1280 × 640. The card uses the bundled Anton font and original mascot. Export `live-cleanup.gif` as H.264 MP4 with an even frame size and `yuv420p` for common social players.
