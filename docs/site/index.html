Three kinds of agent exhaust, handled cleanly

On the author's Mac (~1,000 agent worktrees), BurnZombies reclaimed 685.6 GB in its first two days.

Zombie Processes & Robot Browsers

Stops abandoned Playwright/Puppeteer browsers (often 1–3 GB each), leftover Node workers, and build watchers after their chat closes — polite SIGTERM only after exact PID/start-time/path verification.

Stale Git Worktrees

Removes old agent worktrees after preserving committed HEAD in a local Git ref and local/ignored changes in an encrypted recovery archive. One-click Restore (configurable retention, 7 days default).

Rebuildable Junk & AI Scratch

Clears node_modules, DerivedData, Gradle caches, unused Playwright browser builds, and settled AI temp folders — never touching live chats, main checkouts, or locked worktrees.

Built to pass a security audit

Zero telemetry. 77+ native proof suites. Honest about every boundary.

Complete git worktree lock railLocked worktrees — and the node_modules inside them — are never touched.
Persistent worktree pools protectedSibling checkouts and reusable slot pools (repo1..N, available-*) stay ask-only and never inherit rules from agent worktrees.
Look-only & read-only auditMeasure your Mac first with burnzombies audit or --look-only --observe-only --no-login-item before allowing a single burn.
Configurable backups (7d default)Keep encrypted backups for 1, 3, 7, 14, or any number of days — or turn them off with an explicit warning.
No global agent config editsNever touches ~/.claude.json, ~/.claude/settings.json, or ~/.codex/config.toml. AI sweeps carry BURNZOMBIES_SWEEP=1 attribution tags.
Verify every releaseSigned with Apple Developer ID, notarized by Apple, and published with SHA-256 checksums and Homebrew Cask.
